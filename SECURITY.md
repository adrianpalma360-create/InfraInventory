# Política de Seguridad - InfraInventory

La seguridad de InfraInventory y de las infraestructuras gestionadas es una prioridad fundamental.

---

## 1. Versiones con Soporte de Seguridad

| Versión | Estado de Soporte |
| :--- | :--- |
| **11.x (Actual)** | :white_check_mark: Soportada activamente |
| < 11.0 | :x: No soportada |

---

## 2. Reporte de Vulnerabilidades

Si descubres una posible vulnerabilidad de seguridad en InfraInventory:

1. **NO abras un Issue público** en GitHub para reportar vulnerabilidades de seguridad.
2. Envía un reporte privado detallado al mantenedor del proyecto:
   * **Contacto:** Adrian Palma
   * **Email:** `security@infrainventory.local` (o mediante GitHub Security Advisories privados).
3. Incluye en tu reporte:
   * Pasos reproducibles para manifestar la vulnerabilidad.
   * Versión afectada del sistema.
   * Posible vector de impacto.
   * Prueba de concepto (PoC) si está disponible.

Nos comprometemos a revisar y publicar parches de seguridad de forma prioritaria.
